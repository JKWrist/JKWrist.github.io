## 关于

我的个人技术博客，记录 Linux、C/C++、OpenSSL、Makefile 等领域的技术笔记与开发心得。

- 31 篇文章 · 21 篇速查手册
- 主题为自研深色风格，基于 Jekyll + GitHub Pages
- 评论系统：[Utterances](https://utteranc.es/)（基于 GitHub Issues）

## 本地运行

```bash
# 安装依赖
bundle install

# 本地预览
bundle exec jekyll serve

# 访问 http://localhost:4000
```

## 目录结构

```
.

```
